# roystondwork-dev/homebrew-tap

Homebrew tap for [portcheck](https://github.com/roystondwork-dev/portcheck): see what's using your ports, find free ones, free them up, and check remote hosts.

```sh
brew install roystondwork-dev/tap/portcheck
```

Works on macOS and Linux.

`Casks/portcheck.rb` is generated by GoReleaser on every portcheck release. Please do not edit it by hand, and open issues in the [portcheck repository](https://github.com/roystondwork-dev/portcheck/issues).
